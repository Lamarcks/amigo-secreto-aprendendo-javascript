## 📌 Sobre o projeto

O **Amigo Secreto** é uma aplicação web que permite criar uma lista de participantes e realizar um sorteio de forma aleatória.

O projeto trabalha conceitos fundamentais de JavaScript através de uma aplicação prática e interativa.

O usuário pode adicionar participantes, visualizar os nomes cadastrados, remover pessoas da lista e realizar o sorteio.

---

## 🎯 Objetivo

O principal objetivo do projeto foi desenvolver habilidades em **lógica de programação e JavaScript**, aplicando conceitos como:

* 🧠 Lógica de programação
* 📋 Arrays e manipulação de listas
* 🔀 Estruturas condicionais
* 🔄 Funções
* ✅ Validação de dados
* 🎲 Geração de resultados aleatórios
* 🖥️ Manipulação do DOM
* 💬 Interação com o usuário

---

## ⚙️ Funcionalidades

A aplicação permite:

* ➕ Adicionar participantes à lista
* ✅ Validar campos vazios
* 🚫 Impedir nomes duplicados
* 👥 Visualizar os participantes cadastrados
* 🗑️ Remover participantes
* 🎲 Sortear um participante aleatoriamente
* 📢 Exibir o resultado diretamente na interface

---

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Lamarcks/Projeto-Amigo-Secreto.git
```

### 2. Acesse a pasta do projeto

```bash
cd Projeto-Amigo-Secreto/challenge-amigo-secreto_pt-main
```

### 3. Abra a aplicação

Execute o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code.
